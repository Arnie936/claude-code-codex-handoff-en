# Claude Code ↔ Codex handoff guide

English version of the [original German guide](https://claude-code-codex-handoff.vercel.app/).

A static single-page guide to sharing project instructions, skills, agent definitions, and handoff notes between coding agents. Includes three copyable prompts.

## Local preview

Run `python -m http.server 8000` in this directory, then open <http://localhost:8000>.

## Deployment

Deploy with `vercel --prod`. No build step or dependencies are required.
